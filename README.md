# 📝 Notes App

A responsive and feature-rich Notes Application built using **HTML, CSS, and JavaScript**. This application allows users to create, edit, organize, and manage notes efficiently while automatically saving data using Local Storage, ensuring notes remain available across browser sessions.

## 🚀 Live Demo

[View Live Demo](https://syedabsar99.github.io/notes-app/)

## 📸 Screenshot

![Notes App](preview.png)

## ✨ Features

* Create unlimited notes
* Edit notes directly within the note card
* Delete notes instantly
* Customize notes with different colors
* Automatic data persistence using Local Storage
* Date and time tracking for each note
* Responsive and modern user interface
* No backend or database required

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API

## 🚀 Key Concepts Implemented

* DOM Manipulation
* Event Handling
* Dynamic Element Creation
* Local Storage Management
* JavaScript Date & Time API
* Responsive Web Design
